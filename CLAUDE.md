# Adaptive Home Comfort (fi.oh2th.home-comfort)

Homey Pro (SDK3) app: each zone's temperature from occupancy, energy prices and outdoor
temperature/forecast. Plain JavaScript, CommonJS. Tests: `npm test`.

Public repository: never commit Homey, device, flow or zone names or IDs, real home or room
names, addresses, people's names, e-mails, tokens or keys. Check `git status` before committing.
